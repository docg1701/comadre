# CLAUDE.md

## Language Policy

- **Everything in native English** — all code, comments, commit messages, documentation, Docker configs, environment variables, API responses, error messages, and configuration files.
- **Only exception: `README.md`** — written in Brazilian Portuguese, as it is the public-facing project description.
- This policy exists to optimize LLM interaction and developer experience. Even DevOps deployment docs are in English since the audience is technical staff, not end users.
