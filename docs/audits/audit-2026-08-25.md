### F1 detail (the one worth fixing)

`src/comadre/logging.py::get_logger` gives **each** component logger its own
stdout handler with `propagate=False`. `src/comadre/keys/cli/__init__.py`
re-routes **only** `keys.cli` to stderr (docstring explicitly promises
machine-parseable stdout). Any WARN emitted by `keys.db` / `keys.auth` /
`keys.cache` during a `--format json` command prepends a log line to stdout:

```text
2026-08-25T00:55:11Z | WARN | keys.db | could not chmod 0700 on registry parent dir /tmp ...
[ { ...json... } ]
```

Reproduced with `list-keys --format json` from a DB under `/tmp`. Worst case:
`health --format json` (the monitoring contract, exit 7) emits polluted JSON
whenever a component warns — precisely when operators are watching.
Fix direction: pre-route the known `keys.*` components to stderr eagerly in
`keys/cli/__init__.py` (before command modules import `db`), or give
`get_logger` a stream parameter.
